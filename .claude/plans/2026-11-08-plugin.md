## Planner decisions

- The plugin sits at the marketplace root: `marketplace.json` entry `source: "./"`. The
  brainstorm records root plugins as supported; the scratch validate passed it.
- `plugin.json` sets `name`, `version: "1.0.0"`, `description`, `author`, `repository`; no
  component keys (standard layout).
- `hooks/hooks.json` uses shell form with the quoted variable, as the docs' example, and carries
  the same three event/matcher pairs `install.sh` registers today.
- A new `test/hooks-json.test.sh` guards the one failure `validate` does not check: a hooks.json
  command that names a missing or non-executable script, or drops one of the three registrations.
- `subagent-model-tiering` drops the pointer rather than restating agent count: no skill here
  owns agent count, and the description's job is to say what it is not for.
- `workflow-design/references/platform.md` states the budgets in its own words (text below).
- The machine installment adds before it removes: install and verify the plugin, then remove the
  links and settings entries, so a failed install leaves the current setup intact.
- The template's `slide-designer` names `fakin-claude-config:presentation-narrative`, since the
  bare name is taken by `anthropic-skills`.
